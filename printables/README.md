## 먼저 볼 것 — `학급칠판게시물.html`

**이 파일 하나면 됩니다.** 더블클릭하면 브라우저가 열리고, 왼쪽 목록에서 7장을
눌러 넘겨볼 수 있습니다. 글꼴과 그림까지 안에 들어 있어 **폴더도 인터넷도 필요 없습니다.**
메일이나 USB 로 이 파일만 옮겨도 그대로 동작합니다.

| 단추 | 하는 일 |
|---|---|
| **편집 모드** | 켜면 글자와 빈칸을 눌러 바로 고칠 수 있습니다. 꺼 두면 실수로 안 바뀝니다 |
| **저장** | 고친 내용을 브라우저에 저장. 창을 닫았다 열어도 남아 있습니다 |

| **HTML 내려받기** | 고친 상태 그대로 새 파일로 저장. 다른 컴퓨터로 옮길 때 씁니다 |

## 인쇄하는 법

파일을 **크롬에서 열고** `Ctrl+P`(맥은 `Cmd+P`) 를 누른 뒤 이렇게 맞춥니다.

| 항목 | 설정 |
|---|---|
| 대상 | **PDF로 저장** |
| 용지 크기 | 위 표의 규격 (A2 / A3 / A4) |
| 레이아웃 | 위 표의 방향 (세로 / 가로) |
| 여백 | **없음** |
| 배율 | **기본** (100%). '페이지에 맞추기'로 두면 줄어듭니다 |
| 옵션 | **배경 그래픽 체크** |

**배경 그래픽 체크는 빼먹으면 안 됩니다.** 체크를 안 하면 크림색 바탕과 과목 칸의
색 구분이 전부 날아가 흰 종이에 검은 글씨만 남습니다. CSS 쪽에도
`print-color-adjust: exact` 를 넣어 두었지만, 크롬은 이 체크박스가 최종 결정권을
가져서 CSS 로는 못 덮습니다.

### 인쇄소에 맡길 때 (A2 · A3)

저장한 **PDF 를 그대로** 넘기고 이렇게 요청하세요.

- **실제 크기 100% 로 출력, 축소 금지**
- 용지는 위 표의 규격
- **무광 코팅** 권장 — 유광은 교실 형광등이 반사돼 뒤에서 안 보이고,
  보드마카가 깔끔하게 안 지워집니다

글꼴은 파일 안에 들어 있어 인쇄소 컴퓨터에 따로 깔 필요가 없습니다.

## 고쳐 쓰기

HTML 이라 메모장으로 열어 글자만 바꾸면 됩니다. 자주 고칠 만한 곳:

- **시간표 과목** — `01-timetable-a2.html` 의 `<div class="s ...">과목</div>`.
  칸 색은 클래스로 정합니다: `base`(국영수) · `explr`(통사·통과) · `major`(전공) ·
  `body`(체육·진로) · `creat`(자율·동아)
- **약속 문구** — `04-class-rules-a3.html` 의 `<span class="t">`
- **당번 역할** — `07-duty-a4.html` 의 `<span class="t">`
- **색과 글꼴** — `assets/print.css` 맨 위 `:root` 의 변수 한 곳만 고치면
  7장 전체에 반영됩니다

고친 뒤에는 **넘침 검사**를 돌려 보세요. 글자를 늘리면 내용이 종이 밖으로
밀려날 수 있는데, `overflow: hidden` 때문에 두 장으로 찢어지지 않고 **조용히 잘려**
나갑니다. PDF 가 1페이지인 것만 보고는 절대 못 잡습니다.

```
python3 printables/tools/check_overflow.py
```

## 폴더 구성

```
printables/
├── 학급칠판게시물.html    ← 7장을 묶은 단일 파일 (평소엔 이것만)
├── 01~07-*.html          낱장 원본 7종 — 번들은 여기서 찍어냅니다
├── assets/
│   ├── print.css         팔레트와 공통 부품 — 7장이 같이 씁니다
│   ├── fonts.css         글꼴 선언
│   ├── fonts/            Jua · Gaegu · Gowun Dodum (woff2, OFL)
│   └── svg/              쿼카 4종 + 가을 소품 5종
└── tools/
    ├── trace_quokka.py   원본 쿼카 그림 → SVG 벡터 추적
    ├── build_props.py    가을 소품(단풍잎·은행잎·도토리·밤·감) 생성
    └── check_overflow.py 종이 밖으로 넘치는지 검사
```

`tools/` 는 자산을 다시 만들 때만 씁니다. 인쇄만 할 거면 볼 일 없습니다.

```
python3 printables/tools/trace_quokka.py    # 쿼카 SVG 다시 만들기 (원본 그림 필요)
python3 printables/tools/build_props.py     # 가을 소품 SVG 다시 만들기
```

### 글꼴을 저장소에 같이 넣은 이유

구글 폰트 CDN 을 링크하지 않았습니다. 학교 PC 가 글꼴을 못 받아오면 대체 글꼴로
조판되는데, 글자 폭이 달라지면서 표 칸이 밀리거나 내용이 한 장을 넘어갑니다.
인쇄물은 언제 어디서 뽑아도 똑같이 나와야 해서 오프라인으로 갔습니다.
세 글꼴 모두 SIL Open Font License 1.1 이고 `assets/fonts/OFL-*.txt` 에 원문이 있습니다.

### 쿼카 그림에 대해

선생님이 주신 원본 그림을 **색 영역별로 윤곽선을 따서 벡터로 옮겼습니다.** 손으로
비슷하게 다시 그린 게 아니라 원본 그대로이고, 거친 털 가장자리까지 살아 있습니다.
100% 벡터라 A2 로 키워도 깨지지 않습니다.
